# SnapCompost

SnapCompost is a mobile-first compost management prototype designed to help users monitor compost vessels, track compost progress, and navigate a guided waste-processing workflow.

This project is implemented as a static front-end experience, with the core interface built in `Dasboard.html`.

## Overview

SnapCompost presents a clean, mobile app-inspired dashboard for managing composting activities. It includes:

- compost vessel overview and status monitoring
- progress indicators for each vessel
- notifications and reminders
- guided waste processing workflow
- camera-based or manual entry flow for compost input
- vessel creation and management screens

## Features

- Dashboard with compost inventory and activity summary
- Vessel cards showing readiness progress and compost state
- Notification panel for updates and reminders
- Workflow screens for review, selection, and confirmation
- Camera-style interface for image-based waste review
- Manual input screens for quantity and waste type
- Responsive mobile design with a polished app-like UI

## Project Structure

- `Dasboard.html` — main app interface and styling
- `.vscode/` — editor configuration files

## Technologies Used

- HTML5
- CSS3
- JavaScript

This repository is a frontend prototype and does not include a backend, database, or production deployment setup.
